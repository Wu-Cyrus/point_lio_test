## 2026.2.2 把之前从单片机h7上的代码移植到linux上，目前测试了unilidar和mid360雷达 其他几款雷达代码没有测试过 只是单纯移植 不一定好用

## 1 .雷达配置 ： 略

## 2.依赖配置  ：需要对应版本的fmt ，可以上github克隆该仓库进行下载

- fmt

  ```bash
  git clone https://github.com/fmtlib/fmt
  cd fmt
  mkdir build
  cd build
  cmake ..
  make
  sudo make install
  ```

  注意必须在CMakeLists中添加`add_compile_options(-fPIC)` ！！

## 3.使用说明：/tf订阅即可

1. 纯里程计/建图模式：在config/mid360.yaml  设置use_prior_map为false （如需要保存地图/则设置pcd_save_en为ture 可以自行调整保存帧数或进行后处理）

2. 先验地图定位：在config/mid360.yaml 中 设置use_prior_map为true  设置地图路径prior_map_path 设置yaw搜索范围yaw_range （格式：起始值 间隔 终止值）

3. 里程计的发布帧率与雷达点云发布帧率相同，调整雷达驱动的帧率设置即可改变里程计帧率（也可以修改代码，发布imu的kf状态估计，imu更新频率为200hz，理论上可以以该频率发布）

4. #### TODO 如果设置为高帧率且为建图模式，由于初始化的点云不足，初始化位置会不稳定。若为低帧率，里程计对于高频运动的估计不准确（超出里程计的工作带宽！！！）所以建图时尽量保持运动平稳！！！对于这个问题 可以动态调整帧率（手动累积点云用于初始化）或其他方式（低帧率原地启动建立地图，配合使用高帧率补充地图）

## 4 文件说明：

1. 参数配置：config launch文件中能够配置大部分参数包括地图分辨率imu 协方差 有些参数目前没有写入配置文件中，如icp迭代次数（见文件scan_aligner中的max_iter配置）
2. /PCD 保存先验地图点云文件的默认文件夹，每次保存的名字是一样的，不及时备份会被覆盖
3. /rviz_cfg rviz配置文件 默认了打开rviz2可视化的内容，可以自行调整 （在rviz2中调整设置后覆盖该配置文件即可）
4. /include 主要依赖 包括滤波器实现 流行计算 ikdtree实现
5. /src 主要代码：
   1. Estimator.cpp Estimator.hpp 定义了用于状态估计的滤波器及其计算方法
   2. IMU_Processing.hpp 对imu数据进行处理，包括重力对齐等内容
   3. parameters.hpp parameters.cpp 读取参数表的参数对变量进行初始化，给其他模块使用
   4. preprocess.cpp preprocess.h  对不同类型的数据进行了预处理统一格式
   5. scan_aligner.cpp scan_aligner.hpp 适配ikd-tree的icp方式
   6. laserMapping.cpp 核心代码 包括先验地图加载 里程计数据发布等主干逻辑
